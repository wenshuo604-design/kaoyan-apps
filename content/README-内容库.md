## 数据结构速查

### 词汇表.json（english）
```json
{"word":"the","phonetic":"/ðə/","pos":"","meaning":"这个","freq":"高频","词频":86015,"分类":"抽象概念","组":1}
```
- `freq`：高频/中频/低频（按词频降序三等分）
- `组`：全局组号 1~111，每组50词，第1~37组为高频词，可直接做每日背词计划

### 题库.json（zhuanye）
顶层：`{"统计":{...},"课程":[...],"知识点":[...],"选择题":[...],"大题":[...]}`
```json
// 知识点
{"科目":"液压","章":1,"章名":"第1章 液压传动概述","知识点":"传动原理与帕斯卡原理","内容":"...","序号":1}
// 选择题
{"科目":"液压","章":1,"章名":"...","知识点":"液压传动概述","题型":"选择","题":"...","选项":["A","B","C","D"],"答案":"B","解析":"..."}
// 大题
{"科目":"机械","章":3,"章名":"...","知识点":"轮系传动比","题型":"大题","题":"...","答案":"...","解析":"..."}
```

### 错题模板.json（根目录，四科通用）
```json
{"id":"M-20260902-001","科目":"数学","章节":"...","题型":"选择/填空/大题","题目":"...","我的答案":"","正确答案":"","解析":"","错因":"概念不清/计算失误/审题错误/不会","日期":"2026-09-02","错误次数":1}
```

### 考点.json（math2 / politics）
math2 顶层：`考试结构`（含**明确不考清单**）+ `高等数学` + `线性代数`（模块→考点：名称/考频/常见题型/易错点）
politics 顶层：`考试结构` + `模块`（五块：名称→核心考点：考点/要点/选择题高频问法）

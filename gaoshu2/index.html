📄 导入 Markdown 知识点（自建资料）

选择你自己整理的 .md 文件（可多选）。文件名或文件内第一个 # 标题 会作为知识点名称；支持 $LaTeX$ 公式，导入后即可在知识库中浏览、标记、复盘。

🧩 导入知识包 JSON（整章/整库扩展）

导入别人整理好的知识包（含章节结构），例如后续整理的「线代知识库」包。与现有知识库自动合并，不会覆盖你的学习记录。

💾 数据备份 / 恢复

你的学习记录（掌握度、复盘记录、错题本、讲义进度、打卡）保存在本浏览器 localStorage 中。建议定期导出备份，换电脑/清缓存时可恢复。

📋 错题本导入 / 导出 CSV

在 Excel/WPS 中整理错题后导入；也可导出现有错题。列顺序：日期,来源,章节,知识点,题目,错误解答,错误原因,正确思路,错误类型,状态。类型取值：计算失误/概念不清/方法不会/审题不清/其他；状态：待复习/已掌握。
